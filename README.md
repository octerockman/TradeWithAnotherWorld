# Trade With Another World

Explore the Black Abbey and trade what you recover with the Weathered Wayfarer in this Valheim mod.

## Private playtest

Download the single-DLL install from the [v1.0.13 playtest release](https://github.com/octerockman/TradeWithAnotherWorld/releases/tag/v1.0.13). The ZIP includes short instructions for testers.

## Source

The [v1.0.13 source archive](./TradeWithAnotherWorld-v1.0.13-source.zip) includes the C# source, compiler project, payload index, and map icon sprites. A full rebuild requires the local project assets and Valheim 1.0.21, BepInExPack 5.4.2333, and Jotunn 2.30.2 reference assemblies. Set `ValheimPath`, `BepInExCorePath`, and `JotunnPath` in the compiler project to point to the game directory, BepInEx core directory, and Jotunn DLL respectively.
